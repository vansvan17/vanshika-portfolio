Offensive security course

24 weeks · ~264 hours · live

A course I designed and built, from attacker methodology and web hacking down to binary exploitation, reverse engineering and fuzzing. Each week is a short lesson, then a hands-on lab, then a flag to find. The low-level weeks run on an offline lab box where setuid-root programs guard the flags.

web: SQLi, XSS, IDOR, SSRF, deserialisation · identity and Active Directory · stack and heap exploitation · Ghidra and gdb · AFL++ and libFuzzer · cloud · detection and incident response · capstone assessment
