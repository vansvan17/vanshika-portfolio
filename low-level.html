tinyjit

Compiler · C++ · no dependencies

A small programming language and everything that makes it run. Usually a program is read and acted on one line at a time, which is slow. This one turns the busy parts into the processor's own instructions while the program is running, so it gets close to the speed of compiled C.

~4,000 lines · Pratt parser · SSA and optimization passes · register VM with mark-sweep GC · ARM64 JIT with linear-scan register allocation · writes Mach-O objects · fib(32): 27 ms interpreted, 6 ms JIT-compiled on an M5

Arena allocator

Memory · C++20

A first-fit allocator over raw mmap memory with intrusive free lists and boundary-tag coalescing. 32 cache-line-aligned shards and an ownership prefix let any thread free memory another thread allocated, without one global lock.

21.0 ns per 64-byte allocate/free pair at 16 threads, across 10 runs · cross-thread stress tests pass ASan, UBSan and TSan

Lock-free MPMC queue

Concurrency · C++20

A Michael–Scott queue: many threads put things in and take things out at once, using compare-and-swap instead of locks. Head and tail live on separate cache lines; freeing nodes is deferred on purpose so no thread ever reads reused memory.

4 producers / 4 consumers · 400,000 values checked by exact count and sum under ThreadSanitizer
